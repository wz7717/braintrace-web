# BrainTrace human fixed assets

[HUMAN_FIXED_ASSET_SET_v1](HUMAN_FIXED_ASSET_SET_v1/README.md) contains the exact nine human frozen files and their layered source/notice information. Its file list and inherited identities are in the [public manifest](HUMAN_FIXED_ASSET_SET_v1/SOURCE_AND_NOTICE_MANIFEST.json).

The project's licensable contributions are offered under CC BY-NC 4.0. Third-party material and unprotected facts retain their own scope; the complete mixed files are not uniformly relicensed. Read the set's notices before reuse.

This is a bounded asset set, not an installed inference environment or a complete paper-reproduction package. The [macaque asset set](../macaque_fixed_assets/README.md) is separate. Source code and environment are not included in either new asset directory.
