# BrainTrace application licences

The application, its model assets and the data used to build or run them have component-specific terms. [Component licence guide](docs/DATA_AND_LICENSES.md)

## Code

MIT covers the project contributions in the source and support files identified by the applicable release notice. Scientific code already covered by the BrainTrace MIT notice retains that notice. Third-party libraries retain their own licences. [Release notice](NOTICE.txt) · [MIT licence](licenses/MIT.txt) · [Existing BrainTrace MIT notice](licenses/BrainTrace_existing_MIT.txt)

## Models and references

The human and macaque asset notices apply CC BY-NC 4.0 only to the listed contributions that the project licensor has authority to license. Data and annotations within a model or reference retain their source terms. The asset edition record identifies the Ensembl 97 macaque release. Historical file lists apply to the versions they name. [CC BY-NC 4.0 licence](licenses/CC-BY-NC-4.0.txt) · [Human asset terms](notices/human_fixed/PROJECT_CONTRIBUTION_TERMS.txt) · [Macaque asset terms](notices/macaque_fixed/PROJECT_CONTRIBUTION_TERMS.txt) · [Asset edition](runtime_assets/ASSET_EDITION.json)

## Third-party data, annotations and examples

The human notices identify the applicable terms for GEO inputs, probe-design annotations and Allen-derived material. The macaque notices distinguish the Bo reference data, Ensembl and XSAnno mappings, and PsychENCODE inputs. The example records identify the GEO source studies and the scope of BrainTrace’s contributions to the prepared files.
