# Ensembl source data and project combination

The frozen PsychENCODE mapping preserves recorded Ensembl Compara91 strict one-to-one source relations, XSAnno common IDs, collision exclusions and project combination rules. It does not distribute Ensembl software or a complete annotation database, and does not replace the frozen mapping with a current query.

The recorded [Ensembl legal disclaimer](https://github.com/Ensembl/ensembl-webcode/blob/release/116/htdocs/info/about/legal/disclaimer.html) provides positive scope for access/use and data generated by Ensembl project members; third-party data/software can have separate terms. Ensembl software's Apache-2.0 licence and data terms are different objects. [EMBL-EBI Terms of Use](https://www.ebi.ac.uk/about/terms-of-use/) retain their service/source scope rather than licensing the combined project JSON as one uniform work.

Retain Ensembl project attribution, the recorded Compara91 release and the actually supplied source/creator records. A historical release does not itself create a requirement for a fresh per-release permission. Current-policy source references are not byte authentication of each historical query or all mixed annotation inputs.

Project CC BY-NC 4.0 covers only licensable project combination/organization contributions. It does not relicense third-party content, narrow Ensembl's own open rights or create ownership of factual gene IDs. Actually applicable third-party conditions remain; absent conditions are not invented. Complete upstream databases/software are not included.
