# PsychENCODE frozen mapping and original-source limits

This set includes the original strict Ensembl91/XSAnno mapping, the factual 26514-row PUBLIC_GENE_IDS universe, metadata/SCHEME.json and docs/PSYCHENCODE_INPUT.md. It does not distribute the original count matrix or all PsychENCODE material.

The contract is braintrace.psychencode_common_annotation_input.v1, with public_common_annotation_ln1p_CPM over all 26514 common rows. This is distinct from the original complete sequencing-library background. The Bo-source 43 reference pairs, including the six added source-only pairs, are not trained using external PsychENCODE expression or truth.

These are historical source locators, not a claim that the original station currently supplies the same bytes or a substitute for the frozen mapping. The 247 cross-species columns and 77 rhesus profiles describe prior analysis; the full count, BrainInfo, source annotation, examples and cohort outputs are excluded.

Earlier source examination did not obtain usable current processed-page text or identify full file-specific terms/same-version acquisition for those original processed files. Access failure is not a permission denial. Public counts/factual IDs are not assigned dbGaP genotype restrictions, and article access or 2014 XSAnno CC0 is not enlarged into a blanket 2017 grant.

Providing these fixed authorized mapping/ID assets for an already compatible prepared input does not universally require transferring or rebuilding the original complete matrix. If those original sources are separately redistributed or claimed as exactly reconstructible, their matching acquisition/version and applicable terms need their own evidence. Project CC covers only licensable contributions and does not relicense the whole mixed mapping. Original contracts preserve historical statements and references; read them with the current set manifest, and do not treat referenced code/data as included.
